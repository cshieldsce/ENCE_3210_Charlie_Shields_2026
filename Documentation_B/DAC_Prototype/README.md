# DAC Prototype for Arduino UNO Shield

A prototype of the DAQ we will me using for our Arduino UNO Shield project. The Arduino code can be found in `daq.ino`. The Arduino set the DAQ's input bits so we could verify the output on via viewing the waveform on the oscilloscope. 

## Falstad Circuit
See `circuit_5bit_r2r_daq` for the Falstad circuit simulation file of the simplified 5-bit R2R DAQ.
