Supporting documentation for the Arduino UNO Shield project.

## DAC Prototype
> 📁 [`DAC_Prototype/`](DAC_Prototype/README.md)

A 5-bit R-2R resistor ladder DAC prototype built and tested in lab.

- Arduino sets the DAC's 5 input bits to generate output voltage steps
- Output staircase waveform verified on oscilloscope
- Falstad simulation included: `circuit_5bit_r2r_daq`
